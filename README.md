 Waggle BI Report: Lapcat vs. Lapdog Analysis
🚀 Overview
This project was completed as part of the Udacity Business Intelligence Nanodegree. It focuses on evaluating the performance and market viability of Waggle’s new Lapcat device by comparing it to the highly successful Lapdog product.
Using a fully interactive Power BI dashboard, this analysis answers key executive questions, explores demographic insights, and provides data-driven recommendations to support product strategy decisions.

🧠 Business Context
Waggle recently achieved strong success with its Lapdog fitness collar, which tracks activity and improves pet health outcomes. Based on this success, leadership is considering launching a feline version, Lapcat.
To test viability, 1,000 Lapcat prototypes were distributed for real-world use. This report analyzes the resulting data and compares it to Lapdog performance to determine whether Lapcat is worth scaling.

🎯 Key Business Questions
This report directly addresses leadership’s primary concerns:
1. Activity Impact

Did average daily steps increase for cats using Lapcat, similar to dogs using Lapdog?
How do activity trends compare over time (monthly/yearly)?

2. Customer Satisfaction

Are Lapcat owners as satisfied as Lapdog users?
How do ratings differ between products?

📈 Key Insights


Activity Trends

Lapdog users showed a clear increase in average daily steps over time
Lapcat users showed a more modest / varied change, suggesting differences in behavior between species



Customer Satisfaction

Lapdog consistently received strong user ratings
Lapcat satisfaction was slightly lower / more variable, indicating potential product or expectation gaps



Demographic Patterns

Activity levels varied significantly by breed and pet type
Household income and geography influenced adoption and engagement levels
